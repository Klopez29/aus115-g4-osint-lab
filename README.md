# aus115-g4-osint-lab

Laboratorio de la Discusión #12 de Auditoría de Sistemas (AUS115), Grupo 4, Universidad de El Salvador.

**Todo el contenido es ficticio.** La empresa "Distribuidora Cuscatlán Demo, S.A. de C.V.", las personas, las rutas y las credenciales no existen. Las llaves del archivo `.env` son ejemplos oficiales de la documentación de AWS y una contraseña inventada. No usar con fines reales.

Archivos:
- `.env`: credenciales falsas (riesgo R1).
- `circular_interna_2026.pdf` y `politica_accesos_borrador.docx`: documentos con metadatos plantados (riesgo R2).
